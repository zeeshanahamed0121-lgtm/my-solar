Firebase Connect Manual

Smart Inverter web app ko Firebase Realtime Database se connect karne ka simple guide.

For modern.html Open Modern App

1) Firebase Web Config kahan se leni hai

1
Firebase Console open karoProject smart-inverter-dbb6a select karo.
2
Project Settings me jaoLeft top gear icon ⚙️ → Project settings.
3
Web App add/select karoGeneral tab me “Your apps” ke andar web icon </> select karo. Android appId nahi, Web appId chahiye.
4
SDK setup and configuration copy karoConfig object me se apiKey, messagingSenderId, aur appId copy karo.
Note: Web appId aam tor par :web: wala hota hai. Agar appId me :android: hai to wo Android app ke liye hai.

2) modern.html me config kaise paste karni hai

GitHub repo me modern.html open karo, edit pencil press karo, aur ye line find karo:

const firebaseConfig={apiKey:'YOUR_API_KEY_YAHAN_LIKHEN'

Is config ko apni Firebase Web config se replace karo:

const firebaseConfig = {
  apiKey: 'PASTE_YOUR_API_KEY',
  authDomain: 'smart-inverter-dbb6a.firebaseapp.com',
  databaseURL: 'https://smart-inverter-dbb6a-default-rtdb.asia-southeast1.firebasedatabase.app',
  projectId: 'smart-inverter-dbb6a',
  storageBucket: 'smart-inverter-dbb6a.appspot.com',
  messagingSenderId: 'PASTE_SENDER_ID',
  appId: 'PASTE_WEB_APP_ID'
};
Paste karne ke baad GitHub me Commit changes press karo. 1–2 minutes baad GitHub Pages update ho jata hai.

3) Database paths jo app read karta hai

Modern app pehle /device path read karta hai. Agar data wahan nahi milta to /inverter path bhi check karta hai.

{
  "device": {
    "batteryV": 12.7,
    "batteryPercent": 86,
    "pvV": 37.5,
    "pvA": 7.3,
    "pvW": 274,
    "loadW": 60,
    "grid": 1,
    "charging": 1,
    "invTemp": 38,
    "error": "NONE",
    "fanMode": "AUTO"
  }
}

Agar tumhare ESP8266 keys different hain to app me aliases already diye gaye hain: solarV, solarA, solarPower, batteryVoltage, loadPower, temperature bhi support hain.

4) Firebase Rules test ke liye

Public rules sirf testing ke liye hain. Permanent use ke liye secure rules lagani chahiye.

Testing ke liye Realtime Database → Rules me ye laga sakte ho:

{
  "rules": {
    ".read": true,
    ".write": true
  }
}

Zyada safe version:

{
  "rules": {
    "device": { ".read": true, ".write": true },
    "inverter": { ".read": true, ".write": true },
    "control": { ".read": true, ".write": true }
  }
}

5) Connect hua ya nahi kaise check karo

  • Modern app open karo: modern.html
  • Top right status Online hona chahiye.
  • Firebase me koi value change karo, app me live update aana chahiye.
  • Agar Offline aaye to config, databaseURL, rules aur path check karo.

6) Common errors

!
Offline aa raha haiAPI key/appId wrong, rules blocked, ya database path empty.
!
Values -- aa rahi hainESP8266 data keys app keys se match nahi kar rahe. Example: app pvW ya solarPower read karta hai.
!
AppId errorFirebase Web app create karo. Android appId browser web app me kabhi kabhi issue karta hai.
